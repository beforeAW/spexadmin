# PWA Icons Required

To complete the PWA setup, you need to add the following icon files to the `/public` directory:

## Required Icons:

- `pwa-64x64.png` - 64x64 pixels
- `pwa-192x192.png` - 192x192 pixels
- `pwa-512x512.png` - 512x512 pixels (general purpose)
- `maskable-icon-512x512.png` - 512x512 pixels (maskable for Android adaptive icons)
- `apple-touch-icon.png` - 180x180 pixels (for iOS)
- `favicon.ico` - 32x32 pixels (browser tab icon)

## Icon Guidelines:

- Use the Karspex burgundy (#760408) as primary color
- Include cream (#eedccb) or gold (#d4a814) accents
- Simple, recognizable design that works at small sizes
- Maskable icon should have safe zone (80% of image area)

## Generate Icons:

You can use tools like:

- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- Photoshop/Figma/Illustrator

The PWA is configured and will work once these icons are added.
